# Number Lock Game

A simple browser-based number sequencing game with a placeholder ad banner.

## How to run

1. Open `index.html` in your browser.
2. Or double-click `run.bat` to launch the game in your default browser.

If you have Python installed, you can also run a local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Controls

- Tap the numbers in order from 1 to 9.
- The ad banner at the top rotates sample sponsored messages.
- Click `Restart Game` if you want a new shuffle.
